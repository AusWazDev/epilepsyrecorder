How to Update Icons
To update the in-app icon + non-adaptive launcher icon:
Edit web/mer_icon_full.svg → run npx svgexport web/mer_icon_full.svg assets/app_icon.png 1024:1024 → run dart run flutter_launcher_icons

To update the Android adaptive launcher icon:
Edit web/mer_icon_foreground.svg → run npx svgexport web/mer_icon_foreground.svg assets/app_icon_foreground.png 1024:1024 → run dart run flutter_launcher_icons

To update the splash screen:
Edit source SVGs → re-export PNGs → run dart run flutter_native_splash:create
