Section 3 — How to Update
With MER text (#1 & #2):
Edit web/Blue_background_with_MER.svg or web/Transparent_with_MER.svg → re-export PNG at 1024:1024

Without MER text — in-app + launcher (#3 & #4):
Edit web/Blue_background_without_MER.svg or web/Transparent_without_MER.svg → re-export PNG at 1024:1024 → dart run flutter_launcher_icons

Splash screens:
Edit source SVGs → re-export PNGs → dart run flutter_native_splash:create

Export command:
npx svgexport web/<name>.svg assets/<name>.png 1024:1024
